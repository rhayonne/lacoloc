🔖 Code de référence d'un état des lieux

Chaque état des lieux possède un code unique qui permet de le retrouver facilement, côté locataire comme côté propriétaire.

← Retour au menu principal

À quoi ça sert ?

Le code est généré automatiquement à la création de l'état des lieux. Il est unique, affiché sur les fiches, dans les tableaux et sur le PDF, et il est recherchable : il suffit de le taper dans la barre de recherche pour retrouver l'EDL.

Comment lire le code

EDL E CAEN NL 260605 7F3K
  • EDL — préfixe fixe
  • E / S — Entrée ou Sortie
  • CAEN — l'immeuble (ville/nom)
  • NL — initiales du locataire
  • 260605 — date de l'EDL (AAMMJJ)
  • 7F3K — partie aléatoire (unicité)
ℹ️ Sans locataire nominatif (bail location), les initiales sont remplacées par LOC. Le code reste unique grâce à la partie aléatoire finale.

Où le trouver

Dans le tableau des états des lieux (locataire et propriétaire), le code apparaît sous le nom de l'immeuble / de la chambre :

NL
Maison Test inventaire
Chambre 2 Test · Individuel
EDL-E-LAVA-NL-260605-HFHE
Illustration — ligne du tableau avec le code de référence

Pour le retrouver, tapez le code (ou un extrait) dans la barre de recherche des états des lieux :

🔍 EDL-E-LAVA-NL…
Illustration — recherche par code

Sur le document PDF, le code est rappelé dans l'en-tête (« Réf. ») :

ÉTAT DES LIEUX — ENTRÉE
Maison Test inventaire — Chambre 2 Test
Réf. : EDL-E-LAVA-NL-260605-HFHE
