Enregistrer un immeuble

Ce guide explique comment créer et configurer un nouvel immeuble dans HabitaFrance : type de bien, adresse, photos, type de bail et pièces communes.

⏱ ~5 minutes 👤 Profil : Propriétaire 📅 Mis à jour : juin 2026
Prérequis
ℹ️ Vous devez être connecté avec un compte de type Propriétaire. Si vous voyez un écran de connexion, saisissez vos identifiants et vous serez automatiquement redirigé vers votre tableau de bord.
Étapes
1

Accéder au formulaire de création

Navigation dans la barre latérale du tableau de bord propriétaire

Depuis votre tableau de bord, cliquez sur Gestion Immobilière dans le menu de gauche. Vous arrivez sur l'onglet Mes Propriétés. Cliquez ensuite sur le bouton + Nouveau en haut à droite.

Choisir le type d'immeuble

Premier champ du formulaire — liste déroulante des types disponibles

Le formulaire s'ouvre. Le premier champ est un menu déroulant Type d'immeuble. Les types disponibles sont définis par le Super Admin (ex. : Appartement, Maison, Studio, Colocation…).

🏗️
Type d'immeuble
Sélectionnez la catégorie qui correspond à votre bien dans la liste déroulante. Les options sont gérées par l'administrateur du système.

3

Nom de l'immeuble

Identifiant interne du bien — affiché dans tous les écrans de gestion

🏷️
Nom
Nom court pour identifier l'immeuble dans les listes et les menus. Exemples : « Villa Rosa », « Appartement Bellevue », « Rue Pasteur n°12 ».
⚠ Obligatoire
💡 Choisissez un nom mémorable et unique parmi vos biens. Ce nom apparaîtra dans les états des lieux, les factures et les demandes de contact des locataires.
4

Adresse et localisation

Champ avec auto-complétion via l'API officielle des adresses (data.gouv.fr)

Commencez à saisir l'adresse dans le champ dédié. Des suggestions automatiques apparaissent après quelques caractères. Cliquez sur une suggestion pour remplir automatiquement la ville, le département, la région et le code postal.

📍
Adresse
Saisie libre avec auto-complétion. Tapez au moins 3 caractères pour voir les suggestions de l'API BAN (Base Adresse Nationale).
Optionnel

Ville & Département

🗺️
Région

5

Surface et description

Informations complémentaires sur le bien

📐
Surface totale m²
Surface totale de l'immeuble en mètres carrés. Utilisez un point ou une virgule comme séparateur décimal. Exemple : 85 ou 85,50.
Optionnel
📝
Description
Texte libre décrivant l'immeuble. Visible dans les annonces publiques et les états des lieux. Jusqu'à plusieurs paragraphes.
Optionnel
6

Photos des espaces communs

Galerie d'images des parties communes de l'immeuble

Ajoutez des photos des parties communes (couloirs, façade, jardin, parking, hall…). Ces photos sont distinctes des photos des chambres individuelles.

📸
Photos des espaces communs
Cliquez sur la zone de téléchargement pour sélectionner une ou plusieurs photos depuis votre ordinateur. Formats acceptés : JPG, PNG, WEBP. Les photos sont stockées de façon sécurisée sur Supabase Storage.
Optionnel — mais recommandé pour les annonces
ℹ️ Photo principale : après l'upload, vous pouvez désigner une photo comme "photo principale" en la sélectionnant. C'est cette photo qui sera affichée en vignette dans les listes.

7

Type de bail

Définit la structure contractuelle de l'immeuble

Cette section détermine comment les contrats de location seront gérés. Les deux options sont exclusives.

Section "Type de bail"

TYPE DE BAIL

Location
Un seul contrat pour toute l'immeuble. (Contrat de location classique)
Bail individuel
Contrat séparé pour chaque chambre.
📄
☑ Location
Un seul contrat couvre l'ensemble de l'immeuble. Tous les locataires partagent ce bail unique. Lorsque cette option est cochée, un champ Valeur du loyer (€/mois) apparaît pour saisir le montant global.

Les états des lieux générés seront de type « Location » (parties communes uniquement, un seul EDL pour tous).
🔑
☑ Bail individuel
Chaque chambre a son propre contrat de location. Chaque locataire signe son bail de façon indépendante.

Les états des lieux auront deux composantes : un EDL collectif (parties communes de l'immeuble) et un EDL individuel par chambre.
ℹ️ Les deux options s'excluent mutuellement : cocher « Location » décoche automatiquement « Bail individuel » et vice versa. Vous pouvez modifier ce choix ultérieurement en éditant l'immeuble.

Parties communes et inventaire

Génération automatique des pièces communes standard

Cette section permet de créer d'un seul clic les 7 pièces communes standard de l'immeuble et, si la location est meublée, leur inventaire de base.

🛋️
Location meublée ?
Sélectionnez Oui si l'immeuble est loué meublé, Non sinon. Ce choix détermine si un inventaire de base sera créé avec les pièces communes.

⚠ Ce champ doit être défini avant de cliquer sur "Ajouter les pièces communes".

⚠️ Le bouton "Ajouter les pièces communes et inventaire" ne peut être utilisé qu'une seule fois par immeuble. Après création, il devient grisé pour éviter les doublons. Si vous avez besoin d'ajouter ou de modifier des pièces, rendez-vous dans le détail de l'immeuble après la sauvegarde.
💡 Cliquer sur ce bouton sauvegarde automatiquement l'immeuble si ce n'est pas encore fait (nécessaire pour obtenir l'identifiant de l'immeuble avant de rattacher les pièces).

9

Enregistrer l'immeuble

Sauvegarde du formulaire et confirmation

Une fois tous les champs remplis, cliquez sur le bouton Enregistrer en haut à droite du formulaire.

Nouvel immeuble
💾 Enregistrer
✕ Fermer
↑ Boutons toujours visibles en haut du formulaire
💾
Enregistrer
Valide et sauvegarde l'immeuble. Un indicateur de chargement (spinner) s'affiche pendant l'enregistrement. Un message de confirmation apparaît en bas de l'écran une fois terminé.
✕
Fermer
Ferme le formulaire et retourne à la liste des immeubles. Si des modifications non sauvegardées existent, une boîte de dialogue apparaît pour vous demander si vous souhaitez Continuer l'édition, Quitter sans sauvegarder ou Sauvegarder et quitter.
💡 Après la sauvegarde, l'immeuble apparaît dans la liste Mes Propriétés. Cliquez sur son nom pour accéder à son détail où vous pourrez ajouter des chambres, gérer les pièces et l'inventaire.

Résumé — Récapitulatif des champs
✅ Checklist — Créer un immeuble
  • ✓ Type d'immeuble sélectionné dans la liste déroulante (obligatoire)
  • ✓ Nom de l'immeuble saisi (obligatoire)
  • ✓ Adresse saisie et suggestion sélectionnée (ville / département / région remplis automatiquement)
  • ✓ Surface totale en m² (optionnel)
  • ✓ Description du bien (optionnel mais recommandé)
  • ✓ Photos des espaces communs ajoutées (optionnel)
  • ✓ Type de bail choisi : Location ou Bail individuel
  • ✓ Location meublée ? → Oui ou Non sélectionné
  • ✓ Pièces communes créées via le bouton dédié (recommandé pour les états des lieux)
  • ✓ Bouton Enregistrer cliqué — confirmation de succès reçue
