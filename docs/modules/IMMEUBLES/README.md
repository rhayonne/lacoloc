# Immeubles - Imóveis

## Tipos

- Bail location: Um locatário (ou vários sob 1 contrato)
- Bail individuel: Vários locatários (1 por chambre)

## Estrutura

```
Immeuble
  ├─ Chambres (quartos alugáveis)
  ├─ Pièces (áreas comuns)
  └─ Inventaire (móveis de cada um)
```

## Setup

- Tipo de imóvel (Appartement, Maison, Studio)
- Bail location / Bail individuel
- Charges locatives
- Location meublée (Oui/Non)
- Pièces comuns (gera automático)
