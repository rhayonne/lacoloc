# Chambres - Quartos

## Busca Pública

- Filtros: localização, bail, meublé, superficie, preço, equipamentos, disponibilidade
- RPC `chambre_disponibilite()`: data de liberação
- Sem exposição de identidade do locataire

## Status

- `est_loue = false`: Livre
- `est_loue = true`: Alugado

**Data de disponibilidade**: Inferida de EDL sortie + préavis.
