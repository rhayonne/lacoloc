# Recettes (Échéances)

**Auto-geradas** quando bail está 100% assinado:
```
Loyer mensal × Duração do bail = N échéances
Caução = Loyer × Deposit_Garantie_Mois
```

**Statuts**: a_recevoir, recu, en_retard
**Sens**: recevoir (padrão), payer (remboursement caution)

**Acerto de caution**: Resiliação gera linha payer automaticamente.
