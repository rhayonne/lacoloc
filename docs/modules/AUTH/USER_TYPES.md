# Tipos de Usuário

## 3 Tipos Principais

### Locataire
- Procura quartos
- Solicita contato
- Aceita/assina EDL + bail
- Vê suas recettes/finances

### Proprietaire
- Cadastra imóveis + quartos
- Gestão completa (8 seções)
- Gera EDL + bail
- Vê finances

### Super Admin
- Gere usuários
- Tabelas de referência
- Temas, comunicação
- Maintenance

**Tabela**: User_Types_Reference (code: locataire|proprietaire|super_admin)
