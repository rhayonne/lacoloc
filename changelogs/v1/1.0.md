## 1.0.1 — 2026-06-19

### Notes

Mise à jour **sécurité & stockage** (aucune nouvelle fonctionnalité visible côté
utilisateur, mais durcissement important et migration du contenu sensible).

**🔒 Sécurité — Edge Functions**
- `invite-locataire` (create/resend) : **authentification obligatoire** — seul un
  `proprietaire` / `admin_groupe` / `super_admin` peut créer un compte ou
  réinitialiser un mot de passe. Avant, ces modes étaient ouverts (risque de
  création de comptes et de **prise de contrôle de compte** via `userId`).
- `notify-edl` : **authentification + contrôle d'accès** — l'appelant doit avoir
  accès à l'EDL (vérifié par RLS) ; empêche l'envoi d'e-mails en énumérant les ID.
- Échappement HTML de tous les champs utilisateur dans les e-mails (anti-injection).
- Redirection d'e-mail de test (`mailTo`) verrouillée : honorée uniquement si elle
  correspond au secret serveur `DEV_TEST_EMAIL` (impossible de détourner le lien
  d'activation vers une adresse arbitraire).
- Message d'erreur SMTP générique (ne divulgue plus l'hôte/utilisateur SMTP).

**🔒 Sécurité — Base de données**
- RPC exposant des données personnelles (`search_locataires`,
  `list_invited_locataires`, `notify_edl_*`) : `EXECUTE` révoqué de `anon`/`PUBLIC`
  + contrôle de rôle interne. Avant, ces fonctions étaient appelables sans
  authentification (fuite de noms/e-mails/téléphones de locataires).
- Sanitisation de la recherche des journaux de connexion (anti-injection de filtre).

**📦 Stockage — séparation public / privé**
- Nouveau bucket privé **`documents`** pour le contenu sensible (signatures,
  photos et observations d'états des lieux), avec RLS (accès des deux parties d'un
  EDL via `can_access_edl` ; signatures réservées à leur propriétaire).
- Le bucket **`photos`** reste public pour les annonces (immeubles/chambres/pièces)
  mais ne permet plus de **lister** son contenu.
- Affichage du contenu privé via URL signée temporaire (widget `PrivateImage`).
- Les signatures sont copiées dans l'espace de l'EDL à la finalisation/acceptation
  pour rester lisibles par les deux parties dans le PDF.
- Compatibilité conservée avec les fichiers/URLs existants.

**🛠 Divers**
- Documentation mise à jour (CLAUDE.md, OpenAPI, diagrammes, mémoire projet).
- Tests : ajout de tests pour `StorageService` ; correction d'un test obsolète.
